# Data Sources

This study uses the CMU eVTOL Battery Dataset introduced by Bills et al. (2023) and refers to the mission-phase battery prognostics benchmark developed by Yan and Wiston (2026).

## Original Battery Dataset

Bills et al. (2023), *A battery dataset for electric vertical takeoff and landing aircraft*.

Dataset record: https://doi.org/10.1184/R1/14226830.v3

Article DOI: https://doi.org/10.1038/s41597-023-02180-5

The downloaded archive (`14226830.zip`) contains cell-level measurement files, including `VAH*.csv` and `VAH*_impedance.csv`.

## Reference Benchmark

Yan and Wiston (2026), *Mission-Phase Feature Learning for eVTOL Li-Ion Battery Prognostics*.

Repository: https://github.com/MusaWiston/Mission-Phase-Feature-Learning-for-eVTOL-Battery-Prognostics-with-ML

The benchmark repository contains preprocessing scripts, feature tables, model implementations, and evaluation artifacts.

## Data Availability

Raw battery measurements and third-party benchmark files are not redistributed in this repository. Users should obtain them from their respective original sources, subject to applicable licensing and access conditions.

The accompanying notebook and methodology documentation describe the analysis performed in this study.
